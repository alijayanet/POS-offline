Kebijakan Privasi TokoPOS

Aplikasi: TokoPOS (com.aistudio.tokopos.app)

Pengembang: Ali Jaya Net

Terakhir Diperbarui: 11 Oktober 2026

🛡️ Prinsip Utama: TokoPOS adalah aplikasi kasir dan pembukuan toko yang beroperasi 100% Offline. Seluruh data transaksi, pelanggan, katalog produk, dan laporan keuangan hanya disimpan di perangkat lokal Anda. Kami tidak mengumpulkan, tidak mengunggah, dan tidak menjual data Anda kepada pihak mana pun.

1. Data yang Disimpan & Lokasi Penyimpanan

Seluruh data yang Anda masukkan ke dalam aplikasi TokoPOS, termasuk namun tidak terbatas pada:

  • Informasi Toko (Nama toko, nama pemilik, nomor telepon, alamat, catatan kaki struk).
  • Master Produk (Nama barang, SKU, barcode, harga modal, harga jual, jumlah stok, kategori).
  • Riwayat Transaksi Penjualan, Keuntungan, dan Hutang Pelanggan.
  • Data Pelanggan Tagihan Bulanan (WiFi/TV Kabel/Iuran).

Data tersebut disimpan secara lokal di memori internal smartphone Anda menggunakan database SQLite Room terisolasi milik aplikasi. TokoPOS tidak memiliki server pusat (cloud) untuk menyinkronkan atau mengumpulkan data Anda.

2. Izin Perangkat Android yang Digunakan

Aplikasi TokoPOS hanya meminta izin sistem operasi Android yang benar-benar esensial untuk menjalankan fitur toko:

📷 Izin Kamera (android.permission.CAMERA)

Fungsi: Digunakan untuk memindai barcode fisik pada kemasan produk saat transaksi kasir atau input barang baru, serta memindai QRIS.

Keamanan: Deteksi diproses langsung di HP Anda (on-device) melalui Google ML Kit Vision. Aplikasi TIDAK PERNAH menyimpan foto, merekam video, ataupun mengunggah rekaman visual kamera Anda.

🖨️ Izin Bluetooth (BLUETOOTH_CONNECT & BLUETOOTH_SCAN)

Fungsi: Digunakan untuk menghubungkan HP ke printer thermal Bluetooth (ESC/POS) 58mm & 80mm guna mencetak struk belanja, kuitansi nota manual, dan label barcode barang.

Tanpa Pelacakan Lokasi (neverForLocation): Izin Bluetooth dikonfigurasi dengan flag neverForLocation. Kami tidak pernah mengakses atau melacak lokasi fisik GPS perangkat Anda.

🌐 Izin Internet Umum (android.permission.INTERNET)

Fungsi: Digunakan untuk membuka tautan WhatsApp resmi saat Anda memilih menu kirim struk belanja ke pelanggan via WhatsApp. Aplikasi tidak menggunakan internet untuk mengirimkan data transaksi Anda ke server kami.

3. Cadangan (Backup) & Ekspor Data

TokoPOS menyediakan fitur ekspor laporan ke format Excel/CSV dan cadangan database ke file JSON. Pembuatan file ini hanya terjadi ketika Anda menekan tombol ekspor secara manual. File dibagikan melalui protokol standar Android FileProvider yang aman.

4. Bebas Iklan & Bebas Pelacak Pihak Ketiga

Aplikasi TokoPOS bebas dari modul periklanan pihak ketiga (*Ad Networks*) dan bebas dari pustaka pelacak analitik pengguna (*Tracking SDKs*). Kami tidak melacak aktivitas atau kebiasaan belanja Anda.

5. Hak Pengguna & Penghapusan Data

Anda memegang kendali penuh 100% atas data Anda:

  • Anda dapat mengedit, memperbarui, atau menghapus data produk dan transaksi kapan saja melalui aplikasi.
  • Anda dapat menghapus seluruh data secara instan melalui tombol Reset Database di menu Pengaturan.
  • Anda dapat menghapus seluruh data secara permanen cukup dengan mencopot pemasangan (*Uninstall*) aplikasi TokoPOS dari perangkat smartphone Anda.
